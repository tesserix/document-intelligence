Your image is a test,
not a training dataset.
This sandbox calls the same OCR upload, inspection and processing APIs used by the service. It adds no chat model, JEV or generative extraction. OCR processing itself uses Google Document AI.
Images are removed from dedicated sandbox storage once processing reaches a terminal state. Results and page artifacts expire with the session. Cleanup keeps running if you close the page; outages can delay deletion, and the UI reports it as pending. Minimal job and quota metadata is retained separately. Provider processing is subject to its own data policy.
